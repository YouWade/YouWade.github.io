# YOU, CHENG-WEI | Front-End Engineer

8-bit pixel style personal resume built with modern web technologies.

**Live:** https://youwade.github.io/

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Framer Motion
- Phosphor Icons

## Features

- 8bitcn-inspired pixel decorations (corner squares, dashed borders, pixel shadows)
- Scroll-aware navbar with active section highlighting
- Floating photo animation + text glow effects
- Text scramble skill rotation
- Fully responsive (mobile-first)
- GitHub Actions auto-deploy to GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
